# Momentum - Mi Viaje en Prepa Tec

Un blog personal modular con diseño escandinavo moderno para documentar experiencias, proyectos y momentos especiales de Prepa Tec.

## 🎯 Características

- **Diseño Modular**: CSS organizado en componentes separados
- **Estilo Escandinavo**: Minimalista, limpio y elegante
- **Responsive**: Se adapta perfectamente a todos los dispositivos
- **HTML + CSS puro**: Sin frameworks, fácil de entender y modificar
- **Optimizado**: Imágenes con lazy loading y transiciones suaves

## 🚀 Inicio Rápido

1. **Clona o descarga** este proyecto
2. **Agrega tus imágenes** en la carpeta `images/`
3. **Edita el contenido** en `index.html`
4. **Abre** `index.html` en tu navegador

## 📁 Estructura

```
Mi momentum/
├── index.html              # Página principal
├── styles/                 # Estilos modulares
│   ├── main.css           # Base y variables
│   ├── header.css         # Navegación
│   ├── hero.css           # Sección principal
│   ├── autobiography.css  # Biografía
│   ├── top10.css          # Top 10 momentos
│   └── footer.css         # Footer
├── images/                 # Tus fotos
├── INSTRUCTIONS.md         # Guía detallada de uso
└── README.md              # Este archivo
```
